# Keyboard Shortcuts

| Number | Function | Shortcut keys | Example |
| -------- | -------- | ------------- | ------- |
| 1 | Copy | `ctrl` + `c` | |
| 2 | Cut | `ctrl` + `x` | |
| 3 | Paste | `ctrl` + `v` | |
| 4 | Save | `ctrl` + `s` | |
| 5 | Back | `ctrl` + `z` | |
| 6 | Move to end of word | `ctrl` + `←` / `ctrl` + `→` | |
| 7 | Delete word | `ctrl`  + `backspace` | |
| 8 | Highlight | `shift` | |
| 9 | Highlight to end of word | `shift` + `ctrl` + `←` / `shift` + `ctrl` + `→` | |
| 10 | Move to beginning of line | `home` | |
| 11 | Move to end of line | `end` | |
| 12 | Highlight to end of line | `shift` + `end` | |
| 13 | Highlight to beginning of line | `shift` + `home` | |
| 14 | Move to beginning of document | `ctrl` + `home` | |
| 15 | Move to end of document | `ctrl` + `end` | |
| 16 | Move line up/down | `alt` + `↑` / `alt` + `↓` | |
| 17 | Move window to other monitor | `⊞` + `shift` + `←` / `⊞` + `shift` + `→` | |
| 18 | Switch between windows on the same monitor | `alt` + `tab` | |
| 19 | Search on page | `ctrl` + `f` | |
| 20 | Jump to search bar (google) | `ctrl` + `l` | |
| 21 | Jump to search bar (youtube) | `/` | |
